# proofline

Activate Proofline governance for role-separated work.

Freeze the goal, done signal, editable and protected scope, budget, stop conditions, acceptance oracle, and authority. Route proportionally to sequential, countercheck, or verified-graph mode. Use Keeper, Wayfinder, Countervoice, and Maker only when their separation adds value. Preserve material dissent, exchange typed Proofline signals, and require a complete Proof Return before sealing.

Paseo is optional. Do not install or edit user-level runtime configuration without explicit approval.
